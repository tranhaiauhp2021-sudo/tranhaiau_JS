WEB LABS – HƯỚNG DẪN MỞ TRONG VISUAL STUDIO

1. Giải nén Web_Labs_Visual_Studio.zip.
2. Mở Visual Studio > File > Open > Folder > chọn thư mục Web_Labs_Visual_Studio.
3. Trong Solution Explorer, mở từng thư mục bài tập và mở index.html.
4. Nếu có Open in Browser hoặc View in Browser, chọn lệnh đó; hoặc nhấp đúp index.html bằng File Explorer để mở Chrome/Edge.
5. WebsiteBanHang gồm: index.html, cart.html, style.css, script.js.
6. Lab02_CSS minh họa định dạng văn bản, bảng, danh sách, navigator, bố cục.
7. Lab02a_Layout minh họa layout tuần 04 bằng table, div, HTML5.
8. Khi nộp Git, mở Terminal tại thư mục đã giải nén, chạy:
   git init
   git add .
   git commit -m "Complete web HTML CSS JS labs"
   git branch -M main
   git remote add origin URL_REPOSITORY_CUA_CHI
   git push -u origin main

GHI CHÚ: Website là bài minh họa frontend, ảnh sản phẩm dùng biểu tượng emoji để tránh link ảnh bị lỗi. Phần mua hàng/giỏ hàng là demo chạy trên localStorage, không có thanh toán thật.
