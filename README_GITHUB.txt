BỘ BÀI THỰC HÀNH WEB - HTML / CSS / JAVASCRIPT

Bao gồm các bài cũ và 3 bộ bài mới:
- Tuan03_HTML: Trang home, login, repass, regist và form nâng cao dùng Table
- Tuan06_JS: 3 ví dụ và 7 bài tập JavaScript
- Tuan07_JS: 2 ví dụ và 2 bài tập JavaScript
- Lab02_CSS, Lab02a_Layout, WebsiteBanHang: từ bộ bài trước

Cách chạy: mở folder bằng Visual Studio, tìm index.html trong từng thư mục,
nhấn chuột phải Open in Browser (nếu có) hoặc mở bằng trình duyệt.
Dự án HTML/CSS/JS tĩnh; không yêu cầu npm, Node.js hoặc server.

ĐẨY LÊN GITHUB (dùng Git Bash / Terminal tại thư mục này):
 git init
 git add .
 git commit -m "Hoan thanh bai thuc hanh web"
 git branch -M main
 git remote add origin https://github.com/USERNAME/REPOSITORY.git
 git push -u origin main

Thay USERNAME và REPOSITORY bằng thông tin repo thật.
Nếu repo đã có sẵn: KHÔNG cần git init hoặc remote add lần nữa.
Lưu ý: các form tuần 03 dùng action=google.com method=POST theo đề,
nhưng Google không phải máy chủ tiếp nhận biểu mẫu và có thể từ chối
request. Không nhập mật khẩu thật vào các form demo.

Một số yêu cầu dựa trên API cũ (thanh trạng thái trình duyệt) sẽ được
minh hoạ trong vùng trạng thái trên trang thay vì window.status.
